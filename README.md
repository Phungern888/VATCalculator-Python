# VATCalculator-Python

> แอปพลิเคชันคำนวณภาษีเงินได้บุคคลธรรมดาของประเทศไทย เขียนด้วยภาษา Python

---

## ฟีเจอร์หลัก (Features)
* รองรับการคำนวณภาษีเงินได้บุคคลธรรมดาแบบขั้นบันได 8 ขั้น
* มีฟังก์ชันคำนวณรายได้สุทธิ (หักค่าใช้จ่ายและค่าลดหย่อนส่วนตัวอัตโนมัติ)
* โค้ดอ่านง่าย ยืดหยุ่น และปรับปรุงเรตภาษีได้ง่าย

---

## วิธีการใช้งาน (Getting Started)

### ความต้องการระบบ (Prerequisites)
* Python 3.x ขึ้นไป
